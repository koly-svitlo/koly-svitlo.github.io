# Коли світло ⚡

**Неофіційний сайт графіка відключень електроенергії** для Бердичева та Бердичівського району (Житомиробленерго).

🔗 **Live:** https://koly-svitlo.github.io/  
📦 **Репозиторій:** https://github.com/koly-svitlo/koly-svitlo.github.io

---

## Функціонал

| Функція                          | Опис                                                                            |
| -------------------------------- | ------------------------------------------------------------------------------- |
| 🔍 **Пошук адреси**              | Автодоповнення вулиць з бази обленерго; автоматичне визначення черги по будинку |
| 👥 **Множинні профілі**          | Зберігайте кілька адрес (дім, робота, бабуся) — перемикання одним кліком        |
| ⏱ **Таймер у реальному часі**    | Великий лічильник: скільки залишилось до увімкнення/вимкнення                   |
| 📅 **Експорт в календар (.ics)** | Збережіть графік у телефон — нагадування спрацюють навіть офлайн                |
| ✏️ **Ручне редагування**         | Якщо графік змінився, а сайт ще не оновився — впишіть інтервали власноруч       |
| 🔗 **Діплінки**                  | Посилання типу `…/#4.1` одразу відкривають потрібну чергу                       |
| 🌙 **Теми**                      | Авто / Світла / Темна — запам'ятовується в localStorage                         |
| 📱 **PWA / Офлайн**              | Service Worker кешує сторінку і останній графік — працює без інтернету          |
| ♿ **Доступність**               | ARIA-мітки, фокус-візуалізація, `prefers-reduced-motion`, семантична розмітка   |

```
koly-svitlo.github.io/
├── index.html              # HTML-розмітка

├── eslint.config.js        # ESLint 9 flat config
├── .prettierrc             # Prettier конфіг
├── .github/workflows/
│   ├── update.yml          # Графік: кожні 30 хв
│   ├── addresses.yml       # Адреси: щопонеділка 02:20 UTC
│   └── lint.yml            # Лінт + формат на PR/push
├── scripts/
│   ├── update.mjs          # Скрейпер графіку (Node 20+)
│   └── addresses.mjs       # Скрейпер баз адрес (Node 20+)
├── data.json               # Кеш графіку (оновлюється CI)
├── addresses.json          # База вулиць → черг (оновлюється CI)
├── sw.js                   # Service Worker v3 (offline-first)
├── manifest.webmanifest    # PWA маніфест
├── icon.svg                # Іконка
└── .gitignore
```

### Принципи

- **Zero build** — чисті статичні файли, GitHub Pages обслуговує їх напряму
- **Zero runtime deps** — у продакшн не потрапляє жоден npm-пакет
- **CI as data pipeline** — GitHub Actions скрейплять дані і коммитять JSON у репо
- **Offline-first** — SW: network-first для даних, cache-first для ассетів

## Локальний запуск

```bash
# Встановлення dev-залежностей (для лінту/формату)
npm ci

# Перевірка стилю
npm run lint
npm run format:check

# Автофікс
npm run format

# Оновлення графіку вручну (потребує інтернет, доступу до ztoe.com.ua)
npm run update

# Оновлення бази адрес (весь район ~90 хв, тільки місто --city ~15 хв)
npm run addresses
npm run addresses -- --city
```

> **Важно:** Скрейпери працюють саме в Node.js (не в браузері) через CORS та парсинг HTML. У CI вони запускаються автоматично.

## Схема даних

### `data.json` — графік відключень

```json
{
  "days": {
    "2026-11-20": {
      "updated": "12:30 20.11.2026",
      "q": {
        "1.1": ".................XXXXXX.....XXXXX......XXXXX....",
        "1.2": ".................XXXXXX.....XXXXX......XXXXX...."
      }
    }
  },
  "checked": "2026-11-20T18:35:46.646Z"
}
```

- Ключ `days` — об'єкт за датами (YYYY-MM-DD, Київський час)
- `q` — 12 черг (`"1.1"` … `"6.2"`)
- Значення — **48 символів** по 30 хв: `.` = світло є, `X` = відключення
- `checked` — час останньої перевірки (для індикатора свіжості на сайті)

### `addresses.json` — база адрес

```json
{
  "updated": "2026-11-17",
  "places": [
    {
      "name": "місто Бердичів",
      "streets": [
        {
          "name": "вул. 16-го Липня",
          "rows": [
            {
              "houses": "4, 10, 6, 8, 12, 18, 13, 17, 14, 15, 9, 3",
              "q": "1.1",
              "note": "побутові споживачі"
            }
          ]
        }
      ]
    }
  ]
}
```

- `q: null` + `info` = "не вимикається за графіком" (лише аварійно)
- `note`: `"побутові споживачі"` або `"непобутові (юридичні) споживачі"`

## Розробка

### Додавання нових РЕМ / районів

1. Дізнайтеся `rem_id` на сайті обленерго (параметр форми)
2. Оновіть `REM_ID` в `scripts/addresses.mjs`
3. При потребі — адаптуйте парсери (структура таблиць може відрізнятися)

### Тестування парсерів

```bash
# Перевірка що скрипти не ламаються
node scripts/update.mjs
node scripts/addresses.mjs --city
```

### Стиль коду

- **ES2024**, modules, strict mode
- JSDoc типи для IDE (перевіряються через `jsconfig.json` + `checkJs`)
- Prettier (single quotes, trailing comma es5, 100 cols)
- ESLint (recommended + `no-var`, `prefer-const`, `eqeqeq`)
